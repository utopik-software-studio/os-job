# Roadmap (indicative, not a commitment)

- **v0.14.x — Import et acquisition** : v0.14.0 Centre d'import; v0.14.1 copier-coller (expérimental); v0.14.2 URL; v0.14.3 documents; v0.14.4 CSV; v0.14.5 doublons; v0.14.6 validation; v0.14.7 stabilisation.
- **v0.15.x — Multilingue** : architecture FR/ES/EN, interface, préférences, documents, analyses et formats locaux.
- **v0.16.x — Connecteurs** : centre, plateformes d'emploi, messagerie, calendriers, IA, webhooks et sécurité.
- **v0.17.x — Automatisations** : centre, relances, import, IA, synchronisations, rapports et journalisation.
- **v1.0** : authentification, installation, dépendances, sauvegardes, audit, tests d'installation vierge et distribution.

La roadmap historique figure également dans l'interface. Les versions futures sont des idées, pas des fonctionnalités disponibles.
