# Known limitations / Limites connues

- No authentication, authorization framework or multi-user isolation. Local trusted use only.
- The SQL schema has not yet been smoke-tested against a fresh MariaDB instance.
- Some feature modules and UI workflows have only manual testing.
- Copy/paste extraction uses heuristics; false positives/omissions are possible.
- Optional Ollama AI needs its own local setup.
- Historical code may require further security, dependency and third-party asset review before public release.
- Development paused; no maintenance SLA or promised delivery dates.
