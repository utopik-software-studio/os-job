# Security Policy

**Important:** OS::JOB v0.14.1 has no authentication. It is not suitable for public hosting or use with untrusted users.

Please **do not** post vulnerabilities, credentials, personal data, screenshots with private details, or exploit proofs in public issues. Contact the repository maintainers privately through GitHub's private vulnerability reporting feature **if enabled**; otherwise request a private contact channel without revealing technical details.

No supported security release schedule is currently guaranteed. Do not rely on this project for sensitive production data without an independent security review.
